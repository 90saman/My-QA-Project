# Login Test Cases

## TC_LOGIN_001: Login with valid credentials

**Preconditions:** The user has an existing account.

**Test Steps:**
1. Open the login page.
2. Enter a valid username.
3. Enter a valid password.
4. Click the Login button.

**Test Data:**
- Username: valid_user
- Password: valid_password

**Expected Result:** The user should log in successfully and be redirected to the home page.
